# Sanjeev Vashisht Portfolio Website

A responsive, trilingual portfolio website starter for GitHub Pages.

## Included
- Two visual themes: A (navy + gold) and B (navy + saffron)
- English, Hindi and Punjabi language selector
- Responsive desktop/mobile navigation
- About, leadership, public work, gallery and contact sections
- Static-site hosting; no paid backend required

## Before publishing
1. Confirm every title, role, biography and claim with Sanjeev Vashisht's office.
2. The supplied portrait is included at `assets/sanjeev-vashisht.jpg`.
3. Add verified office address, phone, email and social links.
4. Replace gallery placeholders with approved event photographs.
5. Update the page title and description if needed.

## Run locally
Open `index.html` in a browser. Internet is required for Google Fonts; the site itself works without them using fallback fonts.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `sanjeev-vashisht-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the website. Your URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Portrait included
The supplied Sanjeev Vashisht portrait is already included at `assets/sanjeev-vashisht.jpg`. Keep this filename and folder path when uploading to GitHub.

Do not use an AI-generated or unapproved person's portrait.
