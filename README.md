# Sanjeev Vashisht — BJP Mohali Leadership Presentation

A responsive, animated 16:9 presentation-style portfolio with slide navigation, automatic playback, keyboard controls, fullscreen mode, and English/Hindi/Punjabi language selection.

## Publish on GitHub Pages
1. Create a public repository named `sanjeev-vashisht-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. In Settings → Pages, choose Deploy from a branch, `main`, and `/(root)`.

The site is static and requires no build process.
